# Student Management REST API

A simple Student Management REST API built using **Node.js** and **Express.js**.

## Features

- GET all students
- GET student by ID
- Create a student
- Update a student
- Delete a student
- Logger middleware
- Error handling
- JSON/Array data storage
- Postman API testing

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/students` | Get all students |
| GET | `/students/:id` | Get student by ID |
| POST | `/students` | Create student |
| PUT | `/students/:id` | Update student |
| DELETE | `/students/:id` | Delete student |

## Technologies

- Node.js
- Express.js
- Postman
- JavaScript

**Note:** This project uses in-memory Array/JSON data and does not use a database.
